# FEAT-295 Void ground abilities, wall return and shared Enemy animation layer

## Authorization and scope

2026-10-15 user requests Void ground retreat near the player, player-directed pounce at long range, investigation and repair of ground-to-wall return, and completion of the previously discussed shared Enemy optional-turn/Animation Layer Interface architecture. User explicitly requests shutdown only after both parts are finished and verified. No animation retargeting in TheManTest.

## Findings

- The combat BT's highest-priority FindWallReturn task rejected any combat target beyond MeleeRange. This made return unavailable at far range.
- AVoidGazer::StopWallCrawl called ResetLook even while detached. ResetLook forced CharacterMovement to Falling, so BeginLeap's ground takeoff canceled on its next GA tick. This affected the existing ground-to-wall action as well as new ground hops.
- Ground chase uses the shared player-relative Approach query; it is not random roaming. The wall-ground slam uses a landing point locked near the target at plan time. A later player move can make that attack appear unrelated.

## Implementation

- Removed the far-player return guard. StopWallCrawl resets look only when attached or actively looking, preserving Walking during ground takeoff.
- Added near ground retreat and far ground pounce as BT planned actions. Both use the existing GA_VoidWallLeap/AbilityTask execution and its path, support and collision validation. Retreat has no impact damage. Pounce uses the existing ground impact, warning and charge presentation. Player-relative candidate points never fall back to unrelated random destinations. Return stays first priority after its ground dwell, independent of player range.
- UEnemyAnimInstance now owns the optional bEnableTurnPose switch, RotationRate and TurnWeight. Humanoid and Medusa enable turn pose by default; Void leaves it disabled. Humanoid's authored-turn entry respects the switch; Medusa's existing special layer consumes the common data and retains its idle-action guard.
- Installed ALI_EnemySpecialPose as a pass-through linked layer immediately before DefaultSlot on Humanoid and Void formal graphs. Medusa already used the same interface. Species movement graphs and Void's procedural tentacle proxy remain appropriate to their rigs.
