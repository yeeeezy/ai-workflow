Verify visual fidelity in a rendered gameplay capture at target resolution, separately from build and functional PIE results.

## Spider Tank composition

`UInfiltratorSpiderTankComponent` adds the input-transparent Slate leaf when the robot is remotely possessed and removes it on return. The 1672 × 941 reference dimensions size each transparent module uniformly; top-left title, side guides, center reticle, right-side speed and four bottom control groups use their respective viewport anchors. The bottom groups share the available width in four columns and stay 82 design pixels from the bottom. Slate draws the screen-edge corners, clean single-stroke bottom rail and three separators as vectors instead of extracting the old noisy rail from the render. All letters are drawn in the same Roboto Regular font used by the Lobby, including keycap letters and live amber speed. Slate also applies a faint lower fade and crops the live signal module to the current bar count. Source PNGs and deterministic extraction/import scripts are in `Documentation/SpiderTank/Modules` and `Scripts/UI`. The original blue render and latest approved speed-only render remain separate references.

The latest control copy is `MOVE / CLIMB`, `MOUSE LOOK`, `BLINK TO TARGET` on G, and `RECALL ROBOT` on R. No position or LMB/RMB prompts. Input behavior belongs to `AInfiltratorSpiderTank`; this document covers presentation ownership only.

The current owner opacity revision multiplies extracted shape alpha by 1.25, sets Slate corner/rail alpha to 0.72/0.55 and the lower fade edge to 0.18. Bottom key letters and labels use the same fully opaque muted cyan (`0.43, 0.75, 0.79`) in Lobby Roboto Regular. SPEED remains white and live speed amber.
